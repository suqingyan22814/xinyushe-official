    三分钟上手
    

      
    一、你是谁，能做什么
    
      
    
        
    角色能做什么
    
        
    超级管理员改全部数据、审批申请、下发账号、停用与删除成员
    
        
    编辑改公告、分区、人物、普查、FAQ、群入口等日常数据；史书与公报原文只读
    
        
    只读登录查看，不能保存任何修改
    
      
    

      
    二、改一条公告（最常见）
    
      
      
        
    1. 点上方 数据编辑
      2. 
        
    2. 左侧列表点 news
      3. 
        
    3. 中间编辑器里照着已有的格式改，每条是 {"date":"2026-11-23","name":"标题"}
      4. 
        
    4. 点 ✓ 校验，看到「语法正确」才继续
      5. 
        
    5. 点 👁 查看改动 确认只改了你想要的地方
      6. 
        
    6. 点 保存并提交
      7. 
      
    

      
    三、保存之后为什么网站没变
    
      
    保存是把数据提交到仓库，但站点是「直传部署」，还需要发布一次才上线。这一步由超级管理员执行，通常几分钟内完成。
    

      
    四、常见错误
    
      
    
        
    提示原因与处理
    
        
    JSON 语法错误多半是少了逗号或引号。点「↺ 还原」重来，或对照上一条的格式
    
        
    该文件对当前角色只读史书、公报原文属于档案，只有超管能改
    
        
    提交失败：401登录过期，退出重新登录
    
        
    提交失败：403账号被停用，联系超级管理员
    
      
    

      
    五、几条规矩
    
      
      
        
    • 只改自己负责的部分，别动别人正在写的内容
      • 
        
    • 改完一定点「校验」，语法错的 JSON 会让整个板块打不开
      • 
        
    • 不确定就先点「导出」备份一份，再改
      • 
        
    • 所有提交都会记录账号与时间，可在「操作记录」里查
      •
